Acknowledgements

Many defects in BlinkGTK were fixed thanks to reports from outside the project.
This page records them.

A report with reproduction steps removes our investigation work entirely.
When the environment, version and the reporter's own narrowing-down are
included, we can run the same thing immediately on receipt. Every report below
arrived in that form.

Please file problem reports at
blinkgtk-dist Issues.

Reporter Issue Released in Summary
iche29 dist#5 v1.2.0-build5 Reported that diagnostic PNG output could not be disabled via the environment variable. The reproduction used only the bundled sample, so it ran unchanged on our side
iche29 dist#4 v1.2.0-build4 Reported that continuously animating pages froze in software mode, and separately noted the abnormal exit on shutdown. Keeping the two apart let us trace them independently
iche29 dist#3 v1.2.0-build5 Reported that the bundled sample showed a white window in EGL mode. The report arrived with SHA256 verification already done, so we could rule out the environment immediately
SOTA FUJIWARA — v1.1.0-build3 Reported that the RPM dependency name could not be resolved on Fedora, making it uninstallable. This led us to add a pre-release dependency resolvability check
