BlinkGTK 1.1.0-build4 リリースノート

日付: 2026-07-29 Chromium: 150.0.7871.46 (stable) 状態: 開発版 (1.1.0-dev)。本配布物は検証用途を含みます。

配布形態の刷新 (WebKitGTK 同等構成)

本バージョンから、WebKitGTK と同等に runtime / devel / gir の 3 分割 (バイナリのみ、 GitHub Releases) で配布します。

  • runtime (blinkgtk-bin / libblinkgtk-0.1-0): 共有ライブラリ + Chromium ランタイム (private dir /usr/lib64/blinkgtk-0.1/) + リソース。アプリの実行に必要。
  • devel (blinkgtk-bin-devel / libblinkgtk-0.1-dev): ヘッダ + blinkgtk-0.1.pc + .so symlink。ビルドに必要。
  • gir (blinkgtk-bin-gir): GObject Introspection typelib (Python / GJS 用)。

共有ライブラリの SONAME は libblinkgtk-0.1.so.0 に版数付けされました。各リリースは THIRD_PARTY_NOTICES.html (第三者ライセンス表記) と SHA256SUMS を同梱します。

ハイライト

  • Chromium 150 ベースライン: Chromium 150.0.7871.46 (stable) へ移行。 V8 スナップショット整合・描画スモーク・実機縦組み描画 (EGL 経路含む) を検証済み。
  • 縦書き multicol 列境界の改善 (Issue #110): CSS multicol + writing-mode: vertical-rl (直交ルート) で列境界をまたぐ行が隣接列に欠けて描画される問題に対し、 「列送り軸の line-moves-whole」を成立させる修正を追加。Blink の RuntimeEnabledFeature CJKVerticalColumnFragmentation として実装され、起動フラグ --enable-blink-features=CJKVerticalColumnFragmentation で有効化 (既定は無効 = 従来動作)。
  • 入力系の修正:
    • ホイールスクロールの座標修正 (Issue #112): ポインタが画面中央以外にある時、 ホイールイベントの座標がビューポート中央に固定され中央以外の UI をスクロールできない 問題を修正。
    • スクロールバードラッグ (Issue に関連): スクロールバーのつまみドラッグでスクロール できない問題を修正。
    • top-level ナビゲーション後の入力 (Issue #114): リーダ⇔ライブラリのような top-level ナビゲーションで RenderWidgetHostView が再作成された際、マウス入力が破棄済みの旧 host へ 転送され続ける問題 (要再起動) を修正。
  • GObject 型システム整備: 4 つの列挙/フラグ型 (LoadEvent / LoadError / GpuMode / ContentPolicy) の GType 登録、プロパティ通知 (notify::) の発火、 uri-changed シグナルの実ナビゲーション発火に対応。PyGObject / GJS から機械検証済み。

build4 での変更 (2026-07-29)

本 build4 は、同梱ドキュメントと同梱バイナリの整合性を回復したものです。

同梱ドキュメントの是正 (本 build の主眼)

build2 / build3 の同梱ドキュメントには、同梱バイナリに存在しない API を記載した箇所が 20 種ありました。記載どおりに書くとビルドできない状態で、影響したのは settings-api / c-api-reference / navigation-api / signals-api および 設定・イベントの各チュートリアル、ENGINE_COMPARISON_DETAILED です。

本 build4 で以下のとおり是正しました。

  • 実名への修正: 記載名が実装と食い違っていたもの (例 blink_web_view_set_enable_javascript → blink_web_view_set_javascript_enabled、 blink_web_view_set_auto_load_images → blink_web_view_set_images_enabled)
  • 実装の追加: ユーザーエージェント設定・取得と Cookie 設定を実装 (下記)
  • 未実装ドキュメントの取り下げ: blink-settings-quickstart (INI 形式の設定ファイル API) は実装が存在しないため同梱から外しました。アクセシビリティ API のドキュメントも 同様に取り下げています。実装後に改めて提供します。

利用者が同梱ドキュメントどおりに書いてビルドできることを、配布物そのものを展開して 機械検証するゲートを追加し、本 build から公開の前提条件としています。

追加 API

  • blink_web_view_set_user_agent() / blink_web_view_get_user_agent() — User-Agent の上書きと取得
  • blink_web_view_set_cookie() — Cookie の設定 (非同期、コールバックで結果通知)
  • permission-request シグナルと BlinkPermissionRequest — 位置情報・通知などの権限要求をアプリ側で判断できます。 既定は拒否で、シグナルを処理しない場合はすべて拒否されます。 blink_permission_request_get_type_name() で要求種別を得て、 blink_permission_request_allow() / blink_permission_request_deny() で応答します。

同梱物の変更

  • examples/ に付属していた api_check.c / api_tester.c は、保守されている ソースがリポジトリに存在しない古い検査用プログラムのため同梱を終了しました。
  • examples/Makefile を pkg-config ベースの簡潔なものに差し替えました。従来同梱 されていた Makefile は autotools が生成したもので、生成環境の絶対パスを含み、 配布先ではそのまま動作しませんでした。

配布形態

build3 は RPM のみの差し替えでしたが、本 build4 では tarball / RPM / DEB のすべてを build4 として再生成しています。

build2 での変更 (2026-07-21)

本 build2 は BlinkGTK v1.1 系の初回一般公開版です(build1 は内部検証のみで一般公開していません)。

build1 (2026-07-07) からの差し戻し補間です。同一 Chromium baseline のまま、以下の修正を収録します。

  • アイドル時 CPU 消費の解消 (Issue #115): メインループの fd 監視化と capture damage gate を既定有効化し、静止時の CPU 常時消費 (約 1 コア) をほぼゼロにしました。 切り分け用スイッチ: BLINKGTK_PUMP_LEGACY=1 / BLINKGTK_CAPTURE_DAMAGE_GATE=0。
  • フォントサイズ大変更後の永続白紙の根本修正 (Issue #120): 大規模リフロー直後に ページが白紙のまま固定される事象 (見開き縦書き等) の真因 — リフロー過渡の recording 更新で差分領域が空計算され、白タイルが有効なまま固定される — を特定し、 二段の修正 (invalidation フォールバック + activation 時再 damage) を既定有効で 収録しました。fault injection による決定的な回帰検証系を同梱し、修正の効力は 機械検証済みです。切り分け用: BLINKGTK_120_INVAL_FALLBACK=0 / BLINKGTK_120_ACT_REDRAW=0。
  • メインループ起床保証 (Issue #120 併設): 100ms の起床ハートビートにより、posted task の滞留を有界化 (アイドル負荷は実測 +0.5% 未満)。切り分け用: BLINKGTK_PUMP_RESCUE=0。
  • EGL 分数スケーリングの opt-in 化 (Issue #117): 既定を整数スケールに戻し、実験的な 分数対応は BLINKGTK_EGL_FRACTIONAL=1 の明示 opt-in に変更 (描画退行の回避)。
  • 環境変数リファレンスの整備: 公開サポート env の正リスト (environment-variables-{ja,en}.md) を同梱ドキュメントに追加しました。
  • 診断基盤 (フレーム検査・fault injection 等) は環境変数ゲート (既定無効) で同梱され、 通常運用の挙動には影響しません。

互換性

  • 利用側 (consumer) は PartitionAlloc allocator shim の直接リンクが必要です (同梱の pkg-config blinkgtk-0.1.pc が処理します。Issue #90)。
  • C API に互換性を壊す変更はありません。
  • SONAME 版数付け (libblinkgtk-0.1.so.0) により、consumer は再リンクで versioned な 依存を持ちます。devel パッケージの pkg-config 経由でビルドすれば自動的に整合します。

既知の制限

  • CJKVerticalColumnFragmentation は列幅 600px / column-gap 0 / 直交ルートの border·padding 0 を前提とした段階の実装です (experimental、既定無効)。
  • tarball (FHS) 実行時は runtime の ld.so.conf.d 断片または LD_LIBRARY_PATH で private dir (/usr/lib64/blinkgtk-0.1/) を解決してください。
  • アイドル時の CPU 消費 (Issue #115) は継続調査中です。
