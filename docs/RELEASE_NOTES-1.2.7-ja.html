BlinkGTK 1.2.7-build2 リリースノート

リリース日: 2026-11-20 / Chromium: 158.0.8127.36 / 言語: 日本語 | English

build2: 古い画面を出さないための修正と、X11 向けコードの除去

build1 をお使いの方は、build2 へ更新してください。公開 API に変更はないので、アプリを作り直す必要はありません。

古い画面を出さない — 拡大率 1 の画面でソフトウェア描画を使うときの既定の経路で、いま表示しているページの描画を含まないフレームは、画面へ出さずに捨てるようにしました。また、画面へ出すのを止めている間 (blink_web_view_set_presentation_policy() で BLINK_PRESENT_WARM を指定したとき、または BLINKGTK_PRESENT_POLICY=warm で窓が隠れている間) に取っておいた画面は、その後にページが描き直されていれば、表示を再開したときに出さずに捨てます。前の画面や、ページがまだ入っていない画面が表示されないようにするための修正です。拡大率が 1 以外の画面と、GPU を使う描画には関係しません。

X11 向けのコードを外しました — BlinkGTK の Linux 版は Wayland だけで動きます。使っていなかった X11 向けのコードをライブラリから外しました。使い方と見た目は変わりません。

build1: Chromium 158 へ更新

BlinkGTK のレンダリングエンジンを Chromium 158.0.8127.36 に更新しました。

セキュリティ (Chromium 158)

Chromium 158 のデスクトップ安定版には、上流のセキュリティ修正 204 件が含まれています。修正の詳細はChromium の公式発表をご覧ください。

このリリースは Linux 向けです。以前の版をお使いの場合は、セキュリティ修正を含む本版へ更新してください。

描画と console 出力

software の既定経路では、ページの変わった範囲を GTK と Wayland に更新範囲として渡します。BLINKGTK_T2_DAMAGE=0 で従来の全体更新に戻せます。小さな範囲が変わるページでは合成器へ渡す面積が減りますが、アプリの CPU 時間が下がるとは確認されていません。

BLINKGTK_CONSOLE_STDOUT=0 を指定すると、ページの console メッセージを標準出力へ出さないようにできます。既定では出力します。BlinkGTK のメッセージブリッジには影響しません。

通常の Linux 起動は Wayland 専用です。公開 API に変更はありません。
