BlinkGTK WebGPU Demos

WebGPU capabilities demonstration using BlinkGTK's Chromium 146 rendering engine.

Demos

1. Three.js WebGPU 3D Rendering (threejs-globe/)

Real-time 3D rendering using Three.js WebGPURenderer with four switchable scenes:

  • Globe: Procedurally generated Earth with rotation and starfield
  • Car: Low-poly vehicle on a grid plane with orbiting camera
  • Architecture: Modern building with glass-like translucent materials
  • Abstract: Floating torus knots and icosahedrons with colorful materials

Features: FPS counter, GPU info overlay, particle system, mouse-drag camera control.

2. WebGPU Neural Network Inference (gpu-inference/)

MNIST handwritten digit recognition powered by WebGPU Compute Shaders.

  • Draw digits on a canvas with mouse
  • Real-time GPU inference (3-layer neural network: 784 -> 128 -> 64 -> 10)
  • Layer activation heatmap visualization
  • GPU compute timing display

Requirements

  • BlinkGTK with GPU mode enabled (SwiftShader or native EGL)
  • WebGPU support (Chromium 146+)

Running

# SwiftShader mode (no physical GPU required)
BLINKGTK_GPU_MODE=swiftshader ./simple_browser \
  --url file:///path/to/examples/webgpu-demos/threejs-globe/index.html

# Native EGL mode (physical GPU required)
BLINKGTK_GPU_MODE=egl ./simple_browser \
  --url file:///path/to/examples/webgpu-demos/gpu-inference/index.html

Note: BLINKGTK_GPU_MODE=software (default) does not support WebGPU. WebGPU requires either swiftshader or egl mode.

Technology

  • Three.js r170 (WebGPU build, locally bundled)
  • WebGPU Compute Shaders (WGSL)
  • Chromium 146.0.7680.71 WebGPU implementation
