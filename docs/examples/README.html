BlinkGTK サンプル / BlinkGTK examples

blinkgtk_browser.c

ウィンドウを 1 つ開き、https://google.com/ を表示するだけの最小構成の サンプルです。BlinkGTK を組み込むのに必要なものだけを示しています。

A minimal sample that opens a single window and displays https://google.com/. It shows only what is required to embed BlinkGTK.

ビルド / Build

make

pkg-config から blinkgtk-0.1 が見えている必要があります。RPM / DEB で インストールした場合は設定不要です。tarball を展開して使う場合は次のように 指定してください。

blinkgtk-0.1 must be visible to pkg-config. Nothing is needed if you installed the RPM or DEB. If you extracted the tarball, point it at the extraction directory:

export PKG_CONFIG_PATH=<展開先 / extraction dir>/usr/lib64/pkgconfig:$PKG_CONFIG_PATH

実行 / Run

./blinkgtk_browser                      # https://google.com/ を開く / opens https://google.com/
./blinkgtk_browser https://example.com/ # URL を指定する / specify a URL

Wayland セッションが必要です。BlinkGTK は X11 では動作しません。

A Wayland session is required; BlinkGTK does not run on X11.
