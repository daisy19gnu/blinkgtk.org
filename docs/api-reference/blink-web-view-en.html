BlinkWebView API Reference

Version: v1.1.0
Last updated: 2026-07-29

Overview

BlinkWebView is a widget class for using the Chromium/Blink rendering engine in GTK4 applications. It provides an API similar to WebKitGTK and achieves a high degree of Web standards conformance (98-100%).

Class Hierarchy

GObject (GTK4)
  └─ BlinkWebView

Inherits from:

  • content::WebContentsDelegate (Chromium)
  • content::WebContentsObserver (Chromium)

Constructor

BlinkWebView(BlinkBrowserContext* browser_context)

Creates a new BlinkWebView instance.

Parameters:

  • browser_context: The browser context (session information)

Example:

BlinkBrowserContext* context = new BlinkBrowserContext();
BlinkWebView* web_view = new BlinkWebView(context);

Methods

Widget Management

GtkWidget* GetWidget()

Retrieves the GTK4 widget.

Return value: A pointer to the GTK4 widget

Example:

GtkWidget* widget = web_view->GetWidget();
gtk_window_set_child(GTK_WINDOW(window), widget);

Navigation

void LoadURL(const std::string& url)

Loads the specified URL.

Parameters:

  • url: The URL to load (http://, https://, file://, etc.)

Example:

web_view->LoadURL("https://www.example.com");

void GoBack()

Goes back one entry in the history.

Example:

if (web_view->CanGoBack()) {
  web_view->GoBack();
}

void GoForward()

Goes forward one entry in the history.

Example:

if (web_view->CanGoForward()) {
  web_view->GoForward();
}

void Reload()

Reloads the current page.

Example:

web_view->Reload();

void Stop()

Stops loading the page.

Example:

web_view->Stop();

Navigation State

bool CanGoBack() const

Checks whether it is possible to go back.

Return value: true if going back is possible

bool CanGoForward() const

Checks whether it is possible to go forward.

Return value: true if going forward is possible

Retrieving Information

std::string GetURL() const

Retrieves the current URL.

Return value: The current URL string

Example:

std::string url = web_view->GetURL();
std::cout << "Current URL: " << url << std::endl;

std::string GetTitle() const

Retrieves the current page title.

Return value: The page title string

Example:

std::string title = web_view->GetTitle();
std::cout << "Page title: " << title << std::endl;

content::WebContents* GetWebContents()

Retrieves the internal WebContents (advanced use).

Return value: A pointer to the WebContents

Note: This is an internal API and is not normally used.

Signals (Planned for Future Implementation)

The following signals are planned for implementation in a future version:

  • load-changed - Change in load state
  • load-failed - Load failure
  • title-changed - Title change
  • uri-changed - URI change

Current alternative: Overriding the WebContentsObserver.

Properties (Planned for Future Implementation)

GObject-style properties are planned for implementation in a future version.

Sample Code

Minimal Browser

#include <gtk/gtk.h>
#include "blink_gtk/blink_web_view.h"
#include "blink_gtk/blink_browser_context.h"

static void on_activate(GtkApplication* app, gpointer user_data) {
  // Create window
  GtkWidget* window = gtk_application_window_new(app);
  gtk_window_set_title(GTK_WINDOW(window), "BlinkGTK Browser");
  gtk_window_set_default_size(GTK_WINDOW(window), 1024, 768);

  // Create BlinkWebView
  auto* context = new blink_gtk::BlinkBrowserContext();
  auto* web_view = new blink_gtk::BlinkWebView(context);

  // Load URL
  web_view->LoadURL("https://www.example.com");

  // Add to window
  gtk_window_set_child(GTK_WINDOW(window), web_view->GetWidget());

  gtk_window_present(GTK_WINDOW(window));
}

int main(int argc, char* argv[]) {
  GtkApplication* app = gtk_application_new(
      "com.example.blinkgtk.browser",
      G_APPLICATION_DEFAULT_FLAGS);

  g_signal_connect(app, "activate", G_CALLBACK(on_activate), NULL);

  /* BlinkGTK needs Chromium's browser main loop to run.
   * g_application_run() does not run it, so the page never loads
   * (the navigation never commits). Use register -> activate ->
   * blink_gtk_run_main_loop() instead.
   */
  GError *error = NULL;
  if (!g_application_register(G_APPLICATION(app), NULL, &error)) {
      g_printerr("Failed to register the application: %s\n", error ? error->message : "unknown error");
      g_clear_error(&error);
      g_object_unref(app);
      return 1;
  }
  g_application_activate(G_APPLICATION(app));
  int status = blink_gtk_run_main_loop();
  g_object_unref(app);

  return status;
}

Ease of Migration

Because BlinkGTK adopts an API design similar to WebKitGTK, migration is relatively straightforward.

Migration steps:

  1. webkit_web_view_new() → new BlinkWebView(context)
  2. webkit_web_view_load_uri() → LoadURL()
  3. Signal handlers → WebContentsObserver override (temporary)

Notes

Current limitations

  1. Rendering is Wayland-only - it does not run on X11
  2. Fractional scaling - experimental, opt-in via BLINKGTK_EGL_FRACTIONAL=1

Recommended Uses

  • EPUB 3.3 readers
  • Web-based application frameworks
  • Applications requiring high Web standards conformance
  • Note Lightweight browsers (ServoGTK recommended)
