BlinkGTK API Reference Manual (Table of Contents)

Author: BlinkGTK Project
Target: BlinkGTK API version 0.1 (product v1.1 series) / Chromium 150 baseline

API reference for embedding BlinkGTK into GTK4 applications. This manual is organized as per-chapter files (NN-<slug>-ja.md / -en.md). The Japanese version is canonical; the English version follows it.

The 0.1 in paths and package names is the API version (like GTK4's gtk-4.0), independent of the product version (v1.1.0 etc.); it changes only on incompatible API revisions.

Authoring

  • Draft (Japanese): written from the consumer (embedding) perspective.
  • Review + English translation: BlinkGTK Project handles internal-spec review (semantics, env meanings, deprecations) and the English version.
  • Per-chapter small PRs. Naming: NN-<slug>-ja.md / NN-<slug>-en.md.

Existing documents

Existing *-ja.md files (navigation / settings / signals / c-api-reference / blink-web-view) serve as the base for their chapters and will be consolidated/revised. After migration, old files are replaced with references to the new chapters or merged in.
