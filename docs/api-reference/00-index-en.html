Author: BlinkGTK Project

日本語

The API reference for embedding BlinkGTK in a GTK4 application.
The Japanese pages are canonical; the English pages follow them.

The 0.1 in paths and package names is the API version (the same
convention as GTK4's gtk-4.0). It is independent of the product version
(v1.1.0 etc.) and changes only on incompatible API changes.

About accuracy

This reference is machine-verified:

  • Every API mentioned exists in the shipped header and shared library
  • Every public API in the header is covered by some page
    (experimental APIs are excluded with a stated reason)
  • Every complete code example compiles

Related
