Version: v1.1.0
Last updated: 2026-07-29

About this page

APIs that connect your application and the web page in both directions:

  • Create your own URL scheme — your application answers URLs like
    ebook://book/chapter1.html. A reader application can decrypt the contents
    of a protected EPUB and hand them to the page this way
  • Exchange messages with the page — call C callbacks from the page's
    JavaScript, and call the page's JavaScript from C
  • Inject scripts and CSS into every page — add your application's
    JavaScript or styling without modifying the content itself

Usage

/* Register the "app" scheme; the app answers app://... requests */
static char* on_app_scheme(BlinkWebView *view, const char *uri, gpointer data) {
    return g_strdup("<html><body><h1>Served by the app</h1></body></html>");
}

blink_web_view_register_custom_scheme(view, "app", on_app_scheme, NULL);
blink_web_view_load_uri(view, "app://home/");

Custom URL schemes

blink_web_view_register_custom_scheme()

Registers a URI scheme. Navigating to a URL with that scheme invokes your
callback instead of a network load, and the returned string becomes the page.

Signature:

typedef char* (*BlinkCustomSchemeCallback)(BlinkWebView* web_view,
                                           const char* uri,
                                           gpointer user_data);

void blink_web_view_register_custom_scheme(BlinkWebView* web_view,
                                           const char* scheme,
                                           BlinkCustomSchemeCallback callback,
                                           gpointer user_data);

Return HTML / text / JSON allocated with g_strdup() or similar (BlinkGTK
frees it). Return NULL for a 404.

blink_web_view_register_custom_scheme_full()

The binary-capable variant. Use this for images, audio, fonts — any data that
may contain 0x00 bytes (the text variant truncates at the first 0x00).

Signature:

typedef GBytes* (*BlinkCustomSchemeBytesCallback)(BlinkWebView* web_view,
                                                  const char* uri,
                                                  char** out_mime,
                                                  gpointer user_data);

void blink_web_view_register_custom_scheme_full(BlinkWebView* web_view,
                                                const char* scheme,
                                                BlinkCustomSchemeBytesCallback callback,
                                                gpointer user_data);
  • The response is a GBytes (it carries its own length, so it is binary-safe)
  • Set out_mime to a Content-Type such as g_strdup("image/jpeg"); if left
    unset, the type is guessed from the URI
  • Return NULL for a 404

Example: serving an image from the application

static GBytes* on_ebook_scheme(BlinkWebView *view, const char *uri,
                               char **out_mime, gpointer data) {
    if (g_str_has_suffix(uri, "/cover.jpg")) {
        gsize len = 0;
        gchar *bytes = NULL;
        if (g_file_get_contents("/path/to/cover.jpg", &bytes, &len, NULL)) {
            *out_mime = g_strdup("image/jpeg");
            return g_bytes_new_take(bytes, len);
        }
    }
    return NULL;  /* 404 */
}

JS ↔︎ C messaging

Pages get a window.blinkgtk object.

Direction JavaScript side C side
JS → C window.blinkgtk.postMessage('name', data) receive via blink_web_view_register_message_handler()
C → JS receive via window.blinkgtk.addMessageHandler('name', fn) blink_web_view_send_message_to_page()

blink_web_view_register_message_handler()

Registers a handler for JS → C messages.

Signature:

typedef void (*BlinkMessageCallback)(const char* name,
                                     const guint8* data,
                                     gsize length,
                                     gpointer user_data);

void blink_web_view_register_message_handler(BlinkWebView* web_view,
                                             const char* name,
                                             BlinkMessageCallback callback,
                                             gpointer user_data);

name is an alphanumeric handler name. When the page calls
window.blinkgtk.postMessage('name', data), your callback receives data as
a Base64-encoded byte sequence. Decode with g_base64_decode().

blink_web_view_unregister_message_handler()

Removes a registered handler.

Signature:

void blink_web_view_unregister_message_handler(BlinkWebView* web_view,
                                               const char* name);

blink_web_view_send_message_to_page()

Sends a message from C to the page's JavaScript.

Signature:

void blink_web_view_send_message_to_page(BlinkWebView* web_view,
                                         const char* name,
                                         const char* data);

The page registers its handler first:

<script>
window.blinkgtk.addMessageHandler('page-turn', function (data) {
  console.log('from the app:', data);
});
</script>

Script and CSS injection

blink_web_view_inject_user_script()

Injects JavaScript into the page.

Signature:

void blink_web_view_inject_user_script(BlinkWebView* web_view,
                                       const char* script,
                                       gboolean inject_at_document_start);
  • inject_at_document_start=TRUE: stored, and executed at the start of every
    subsequent page load    , before the page's own scripts. Use this to override
    page APIs
  • FALSE: executed immediately in the current page (equivalent to
    blink_web_view_execute_javascript())

blink_web_view_inject_user_stylesheet()

Injects CSS into the current page and future pages.

Signature:

void blink_web_view_inject_user_stylesheet(BlinkWebView* web_view,
                                           const char* css);

Useful for reader features like a dark theme or line-height adjustment without
touching the content.

blink_web_view_remove_all_user_scripts()

Removes all injected scripts and stylesheets.

Signature:

void blink_web_view_remove_all_user_scripts(BlinkWebView* web_view);

Complete example: a custom scheme plus a notification from the page

The application serves app://home/, and a button in the page notifies C.

#include <blink_gtk/blink_gtk.h>
#include <gtk/gtk.h>

static char* on_app_scheme(BlinkWebView *view, const char *uri, gpointer data) {
    return g_strdup(
        "<html><body>"
        "<h1>Served by the app</h1>"
        "<button onclick=\"window.blinkgtk.postMessage('clicked','hello')\">"
        "Notify C</button>"
        "</body></html>");
}

static void on_message(const char *name, const guint8 *data,
                       gsize length, gpointer user_data) {
    gsize out_len = 0;
    guchar *decoded = g_base64_decode((const gchar *)data, &out_len);
    g_print("from page '%s': %.*s\n", name, (int)out_len, decoded);
    g_free(decoded);
}

int main(int argc, char **argv) {
    blink_gtk_init(&argc, &argv);

    GtkWidget *win = gtk_window_new();
    gtk_window_set_default_size(GTK_WINDOW(win), 800, 600);

    GtkWidget *view = blink_web_view_new();
    gtk_window_set_child(GTK_WINDOW(win), view);

    blink_web_view_register_custom_scheme(BLINK_WEB_VIEW(view), "app",
                                          on_app_scheme, NULL);
    blink_web_view_register_message_handler(BLINK_WEB_VIEW(view), "clicked",
                                            on_message, NULL);

    gtk_window_present(GTK_WINDOW(win));
    blink_web_view_load_uri(BLINK_WEB_VIEW(view), "app://home/");

    return blink_gtk_run_main_loop();
}

Build:

cc -o app-integration app-integration.c $(pkg-config --cflags --libs blinkgtk-0.1)
