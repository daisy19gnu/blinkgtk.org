概要

BlinkGTK の C API は blink_gtk/blink_gtk.h で定義されています。
WebKitGTK と同様の設計思想で、C 言語から直接使用できる API を提供します。

スレッド安全性ポリシー

全ての BlinkGTK 公開 API 関数は GTK メインスレッドからのみ呼び出し可能 です。
ワーカースレッドやバックグラウンドスレッドから呼び出した場合の動作は未定義です。
GTK メインスレッド外から操作を行う必要がある場合は g_idle_add() を使用して
メインスレッドにディスパッチしてください。

/* ワーカースレッドからの安全な呼び出し例 */
static gboolean load_on_main_thread(gpointer data) {
    const char* uri = (const char*)data;
    blink_web_view_load_uri(BLINK_WEB_VIEW(g_web_view), uri);
    return G_SOURCE_REMOVE;
}

/* ワーカースレッド内 */
g_idle_add(load_on_main_thread, "https://example.com");

NULL ガードポリシー

v1.1.0 以降、全ての公開 API 関数は g_return_if_fail() / g_return_val_if_fail() による
NULL チェックを行います。NULL ポインタを渡した場合、GLib の警告メッセージが出力され、
関数は安全にリターンします（クラッシュしません）。

/* NULL を渡した場合の動作 */
blink_web_view_load_uri(BLINK_WEB_VIEW(NULL), "https://example.com");
/* 出力: (process:PID): BlinkGTK-CRITICAL **: blink_web_view_load_uri: assertion 'web_view != NULL' failed */

インクルードパスの設定:

pkg-config --cflags blinkgtk-0.1
#include <blink_gtk/blink_gtk.h>

初期化・終了 API

blink_gtk_init(&argc, &argv)

gboolean blink_gtk_init(int* argc, char*** argv);

BlinkGTK を初期化します。ウィジェット作成前に必ず呼ぶ必要があります。

パラメータ 型 説明
argc int* main() の argc のアドレス（NULL 可）
argv char*** main() の argv のアドレス（NULL 可）

戻り値: 初期化成功なら TRUE、失敗なら FALSE

スレッド安全性: メインスレッドからのみ呼び出し可能。

使用例:

int main(int argc, char* argv[]) {
    if (!blink_gtk_init(&argc, &argv)) {
        g_critical("BlinkGTK initialization failed");
        return 1;
    }
    /* ... */
}

blink_gtk_run_main_loop()

int blink_gtk_run_main_loop(void);

Chromium のメインループを開始します。blink_gtk_quit_main_loop() が呼ばれるまでブロックします。

戻り値: 終了コード（通常 0）

注意: GTK の g_application_run() ではなく Chromium の base::RunLoop を使用しています。

blink_gtk_quit_main_loop()

void blink_gtk_quit_main_loop(void);

blink_gtk_run_main_loop() で開始したメインループを終了します。

blink_gtk_shutdown()

void blink_gtk_shutdown(void);

BlinkGTK をシャットダウンします。アプリケーション終了時に呼び出します。

注意: v1.1.0 以降、内部で _exit(0) を呼び出して DiscardableSharedMemoryManager の DCHECK を回避しています。

ナビゲーション API

blink_web_view_load_uri()

void blink_web_view_load_uri(BlinkWebView* web_view, const char* uri);

指定した URI を BlinkWebView にロードします。

パラメータ 型 説明
web_view BlinkWebView* 対象の BlinkWebView
uri const char* ロードする URI 文字列

対応 URI スキーム:

  • https:// / http:// — 通常の Web ページ
  • file:// — ローカルファイル

インライン HTML の読み込み:

インライン HTML を表示する場合は blink_web_view_load_html() を使用してください
（data:URL→load_html()移行）。

blink_web_view_load_uri(BLINK_WEB_VIEW(web_view), "https://www.google.com");

/* data:URL→load_html()移行 — インライン HTML は load_html() を使用 */
blink_web_view_load_html(BLINK_WEB_VIEW(web_view),
    "<!DOCTYPE html><html><body style='margin:0'>"
    "<div style='display:block;background:#0000ff;width:800px;height:200px'>BLUE</div>"
    "</body></html>", NULL);

注意: blink_web_view_load_html() ではプレーン HTML をそのまま渡せるため、
data: URL のエンコーディング（%23 等）は不要です。#ffe 等の CSS 色指定もそのまま使用可能です。
DOCTYPE を含めてください。ないと quirks モードになり、div がインライン要素として扱われます。

blink_web_view_load_html()

void blink_web_view_load_html(BlinkWebView* web_view,
                              const char* html,
                              const char* base_uri);

v1.1.0 以降 -- HTML 文字列を直接読み込みます。WebKitGTK の
webkit_web_view_load_html() と互換性のある API です。

パラメータ 型 説明
web_view BlinkWebView* 対象の BlinkWebView
html const char* ロードする HTML 文字列
base_uri const char* 相対 URL の解決に使用するベース URI（NULL 可）

base_uri が NULL の場合、about:blank がベース URI として使用されます。

使用例:

/* 基本的な使用 */
blink_web_view_load_html(BLINK_WEB_VIEW(web_view),
    "<!DOCTYPE html><html><body><h1>Hello</h1></body></html>",
    NULL);

/* ベース URI を指定して相対パスの画像を解決 */
blink_web_view_load_html(BLINK_WEB_VIEW(web_view),
    "<!DOCTYPE html><html><body><img src='logo.png'></body></html>",
    "https://example.com/");

blink_web_view_load_uri() との違い:

API 用途
blink_web_view_load_uri() URL を指定してネットワーク経由でページを読み込む
blink_web_view_load_html() HTML 文字列を直接レンダリングする（ネットワーク不要）

スクリーンショット API

blink_web_view_capture_screenshot()

gboolean blink_web_view_capture_screenshot(BlinkWebView* web_view,
                                           const char* filename);

現在のレンダリングフレームを PNG 形式で保存します。

パラメータ 型 説明
web_view BlinkWebView* 対象の BlinkWebView
filename const char* 保存先のファイルパス（.png 拡張子推奨）

戻り値: キャプチャ開始に成功したら TRUE

注意: 非同期処理です。ファイルが書き込まれるまでに時間がかかる場合があります。

推奨タイミング: ナビゲーション完了後 30 秒以上待機してからキャプチャしてください。
Renderer 初期化に約 25 秒かかります。

使用例:

/* 30秒後にスクリーンショット撮影 */
static gboolean take_screenshot(gpointer data) {
    BlinkWebView* view = (BlinkWebView*)data;
    blink_web_view_capture_screenshot(BLINK_WEB_VIEW(view), "/tmp/blinkgtk_screenshot.png");
    return G_SOURCE_REMOVE;
}
g_timeout_add_seconds(30, take_screenshot, web_view);

blink_web_view_capture_screenshot_async()

typedef void (*BlinkScreenshotCallback)(BlinkWebView* web_view,
                                        gboolean success,
                                        const char* filename,
                                        gpointer user_data);

void blink_web_view_capture_screenshot_async(BlinkWebView* web_view,
                                             const char* filename,
                                             BlinkScreenshotCallback callback,
                                             gpointer user_data);

v1.1.0 以降 -- 非同期スクリーンショットをコールバック方式で取得します。
blink_web_view_capture_screenshot() の非同期版で、完了時にコールバックが呼ばれます。

パラメータ 型 説明
web_view BlinkWebView* 対象の BlinkWebView
filename const char* 保存先のファイルパス（.png 拡張子推奨）
callback BlinkScreenshotCallback 完了時に呼ばれるコールバック関数
user_data gpointer コールバックに渡すユーザーデータ

コールバックのパラメータ:

パラメータ 型 説明
web_view BlinkWebView* 対象の BlinkWebView
success gboolean 保存成功なら TRUE
filename const char* 保存先のファイルパス
user_data gpointer blink_web_view_capture_screenshot_async() に渡した user_data

使用例:

static void on_screenshot_done(BlinkWebView* view,
                               gboolean success,
                               const char* filename,
                               gpointer user_data) {
    if (success) {
        printf("Screenshot saved: %s\n", filename);
    } else {
        printf("Screenshot failed: %s\n", filename);
    }
}

blink_web_view_capture_screenshot_async(BLINK_WEB_VIEW(web_view),
                                        "/tmp/blinkgtk_async.png",
                                        on_screenshot_done,
                                        NULL);

blink_web_view_get_cookies()

指定 URL の Cookie を非同期で取得します。callback には "a=1; b=2" 形式の

完全なサンプルプログラム

#include <blink_gtk/blink_gtk.h>
#include <gtk/gtk.h>
#include <stdio.h>
#include <unistd.h>

static BlinkWebView* g_web_view = NULL;

static gboolean quit_timer(gpointer data) {
    printf("Auto-quit after 45 seconds\n");
    blink_gtk_quit_main_loop();
    return G_SOURCE_REMOVE;
}

static gboolean screenshot_timer(gpointer data) {
    if (g_web_view) {
        blink_web_view_capture_screenshot(BLINK_WEB_VIEW(g_web_view), "/tmp/blinkgtk.png");
        printf("Screenshot captured\n");
    }
    return G_SOURCE_REMOVE;
}

int main(int argc, char* argv[]) {
    /* 初期化 */
    if (!blink_gtk_init(&argc, &argv)) {
        fprintf(stderr, "Failed to initialize BlinkGTK\n");
        return 1;
    }

    /* BlinkWebView 作成 */
    g_web_view = BLINK_WEB_VIEW(blink_web_view_new());
    if (!g_web_view) {
        fprintf(stderr, "Failed to create BlinkWebView\n");
        blink_gtk_shutdown();
        return 1;
    }
    g_object_ref_sink(g_web_view);

    /* data:URL→load_html()移行 — インライン HTML ロード */
    blink_web_view_load_html(BLINK_WEB_VIEW(g_web_view),
        "<!DOCTYPE html><html>"
        "<body style='background:#00ff00'>Hello BlinkGTK</body></html>", NULL);

    /* タイマー設定 */
    g_timeout_add_seconds(30, screenshot_timer, NULL);  /* 30秒後スクリーンショット */
    g_timeout_add_seconds(45, quit_timer, NULL);         /* 45秒後終了 */

    /* メインループ */
    int status = blink_gtk_run_main_loop();

    /* クリーンアップ */
    if (g_web_view) {
        g_object_unref(g_web_view);
        g_web_view = NULL;
    }
    blink_gtk_shutdown();

    return status;
}

環境変数

BLINKGTK_GPU_MODE

GPU 描画モードを制御する環境変数です。未設定の場合は software モードで動作します。

値 動作 用途
software（デフォルト） ソフトウェア描画（--disable-gpu-compositing） 仮想環境、ヘッドレス、安定性重視
swiftshader SwiftShader GL エミュレーション GPU 非搭載環境での GL 利用
egl ネイティブ EGL 実 GPU 搭載環境での高速描画

使用例:

# デフォルト（ソフトウェア描画）
./blinkgtk_browser

# SwiftShader GL エミュレーション
BLINKGTK_GPU_MODE=swiftshader ./blinkgtk_browser

# ネイティブ EGL（実 GPU 必要）
BLINKGTK_GPU_MODE=egl ./blinkgtk_browser

注意: egl モードは実際の GPU ハードウェアが必要です。仮想環境や Weston headless では
software または swiftshader を使用してください。
