BlinkGTK API リファレンスマニュアル(目次)

作成者: BlinkGTK Project 対象: BlinkGTK API バージョン 0.1(製品バージョン v1.1 系)/ Chromium 150 baseline

BlinkGTK を GTK4 アプリケーションに組み込むための API リファレンスです。本マニュアルは章別の分冊(NN-<slug>-ja.md / -en.md)で構成されます。日本語版を正とし、英語版がこれに追随します。

パス・パッケージ名中の 0.1 は API バージョンです(GTK4 の gtk-4.0 と同じ規約)。製品バージョン(v1.1.0 等)とは独立で、互換性のない API 変更時にのみ変わります。

分担 / Authoring

  • 草稿(日本語): consumer(組み込み利用)視点で起草。
  • 監修 + 英語版追随: BlinkGTK Project 側が内部仕様の監修(セマンティクス訂正・env 意味確定・非推奨指定)と英語版整備を担当。
  • 章ごとの小 PR で進行。命名は NN-<slug>-ja.md(日本語)/ NN-<slug>-en.md(英語)。

既存ドキュメントの扱い

既存の *-ja.md(navigation / settings / signals / c-api-reference / blink-web-view)は各章の母体として統合・改訂の対象です。章別ファイルへの移行後は、旧ファイルは新章への参照に置き換えるか、統合します。
