BlinkGTK API リファレンスマニュアル(目次)

作成者: BlinkGTK Project
対象: BlinkGTK API バージョン 0.1(製品バージョン v1.2 系)/ Chromium 151 baseline

English

BlinkGTK を GTK4 アプリケーションに組み込むための API リファレンスです。
日本語版を正とし、英語版がこれに追随します。

パス・パッケージ名中の 0.1 は API バージョンです(GTK4 の gtk-4.0 と
同じ規約)。製品バージョン(v1.1.0 等)とは独立で、互換性のない API 変更時に
のみ変わります。

記載の正確性について

このリファレンスは機械検証されています。

  • 記載されたすべての API が、配布物のヘッダと共有ライブラリに実在すること
  • ヘッダのすべての公開 API が、いずれかのページに記載されていること
    (実験的 API は理由付きで除外リストに登録)
  • 完全なコード例がコンパイルできること

関連

  • インストール・依存: 配布物同梱の INSTALL.md、および blinkgtk-dist リポジトリ
  • 環境変数は「公開サポート / エスケープハッチ / 内部診断」の 3 区分。内部診断 env は無保証・サポート対象外です。
