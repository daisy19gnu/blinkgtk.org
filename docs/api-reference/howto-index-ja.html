Documentation · BlinkGTK

逆引きリファレンス — 「したいこと」から関数を探す

作成者: BlinkGTK Project

English | API 目次

やりたいことから関数名を引くための索引です。使い方・引数・完全なコード例は
「詳細」列のページを参照してください。記載されている関数はすべて、配布物の
ヘッダと共有ライブラリに実在することを機械検証しています。

起動と終了

したいこと 関数 詳細
Chromium リソース (icudtl.dat 等) の場所を教える blink_gtk_set_resources_path() / blink_gtk_set_icu_data_path() C API
エンジンを初期化する (GTK より先に呼ぶ) blink_gtk_init() C API
メインループを回す・止める blink_gtk_run_main_loop() / blink_gtk_quit_main_loop() C API
終了処理をする blink_gtk_shutdown() C API
BlinkGTK / Chromium のバージョンを調べる blink_gtk_get_version() / blink_gtk_get_chromium_version() C API

したいこと 関数 詳細
WebView を作る blink_web_view_new() BlinkWebView
GPU モードを指定して WebView を作る・調べる blink_web_view_new_with_gpu_mode() / blink_web_view_get_gpu_mode() Settings API
URL を開く blink_web_view_load_uri() Navigation API
HTML 文字列をそのまま表示する blink_web_view_load_html() Navigation API
戻る・進む (可否の確認も) blink_web_view_go_back() / blink_web_view_go_forward() / blink_web_view_can_go_back() / blink_web_view_can_go_forward() Navigation API
再読み込みする・読み込みを中止する blink_web_view_reload() / blink_web_view_stop() Navigation API
現在の URL・タイトルを取る blink_web_view_get_uri() / blink_web_view_get_title() Navigation API
読み込み中かどうか・進捗を知る blink_web_view_is_loading() / blink_web_view_get_estimated_load_progress() Navigation API

UI を自前にする

したいこと 関数 詳細

この索引に載っていない関数

公開ヘッダの全関数 (非推奨・実験的なものを含む) は
C API リファレンスの全関数索引 にあります。
シグナル (load-changed / title-changed / permission-request 等) は
Signals API を参照してください。
