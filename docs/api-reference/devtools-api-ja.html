English

このページについて

表示中のページを Chrome DevTools でデバッグするための API です。
DOM の検査、コンソール、ネットワーク、パフォーマンス計測など、Chrome と
同じ開発者ツールがそのまま使えます。

使い方

/* リモートデバッグを開く (ポート 0 = 自動割り当て) */
gint port = blink_web_view_open_devtools(view, 0);
if (port > 0) {
    char *url = blink_web_view_get_devtools_url(view);
    g_print("DevTools: %s\n", url ? url : "(URL 取得失敗)");
    g_free(url);
}

表示された URL を Chrome / Chromium で開くか、chrome://inspect から
接続します。

API

blink_web_view_open_devtools()

リモートデバッグを指定ポートで開きます。

シグネチャ:

gint blink_web_view_open_devtools(BlinkWebView* web_view, gint port);

port に 0 を渡すと空きポートが自動で選ばれます。戻り値は実際に使われる
ポート番号で、失敗時は 0 です。

blink_web_view_close_devtools()

リモートデバッグ接続を閉じます。

シグネチャ:

void blink_web_view_close_devtools(BlinkWebView* web_view);

blink_web_view_get_devtools_url()

DevTools フロントエンドの URL を返します。呼び出し側が g_free() で
解放します。未接続時は NULL です。

シグネチャ:

char* blink_web_view_get_devtools_url(BlinkWebView* web_view);

blink_gtk_set_devtools_locale() / blink_gtk_get_devtools_locale()

DevTools の表示言語を設定・取得します。"ja" を設定すると DevTools の
UI が日本語になります。blink_gtk_init() より前に呼んでください。

シグネチャ:

void blink_gtk_set_devtools_locale(const char* locale);
const char* blink_gtk_get_devtools_locale(void);

注意

  • リモートデバッグポートは localhost からのみ利用する前提です。外部に
    開放しないでください
  • 製品ビルドでは、デバッグ用の隠しオプションなどからのみ開けるようにする
    ことを推奨します
