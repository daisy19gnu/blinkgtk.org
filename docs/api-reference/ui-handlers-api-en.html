BlinkGTK UI Handlers API Reference — Dialogs, File Chooser, Downloads, Authentication

Version: v1.1.0
Last updated: 2026-07-29
Language: English |

日本語

About this page

APIs that let your application take over the browser UI a page asks for:
JavaScript alert(), file selection, choosing where downloads go, HTTP
authentication, and certificate errors — all with your own dialogs and
policies.

Every handler has a defined default when unset, so you only implement the
ones you need.

Page request Default when no handler is set
alert() Auto-accepted
confirm() / prompt() Auto-cancelled (false / empty)
File chooser (<input type="file">) Cancelled
Download Saved to ~/Downloads/
HTTP auth (401 / 407) Cancelled
Certificate error Logged and allowed (a development default — implement the handler for production)

Usage

/* The app decides where downloads go */
static char* on_download(BlinkWebView *view, const char *url,
                         const char *suggested, const char *mime,
                         gpointer data) {
    return g_build_filename(g_get_home_dir(), "MyApp", suggested, NULL);
}

blink_web_view_set_download_handler(view, on_download, NULL);

Overview

What you want API

Your own file chooser UI blink_web_view_set_file_chooser_handler() + blink_web_view_file_chooser_response()

JavaScript dialogs

blink_web_view_set_javascript_dialog_handler()

Receives alert() / confirm() / prompt() / beforeunload requests.

Signature:

typedef enum {
  BLINK_JS_DIALOG_ALERT = 0,
  BLINK_JS_DIALOG_CONFIRM = 1,
  BLINK_JS_DIALOG_PROMPT = 2,
  BLINK_JS_DIALOG_BEFORE_UNLOAD = 3,
} BlinkJSDialogType;

typedef void (*BlinkJSDialogResponseCallback)(gboolean success,
                                              const char* input_text,
                                              gpointer user_data);

typedef gboolean (*BlinkJSDialogRequestCallback)(
    BlinkWebView* web_view,
    BlinkJSDialogType dialog_type,
    const char* message,
    const char* default_prompt,
    BlinkJSDialogResponseCallback response_callback,
    gpointer response_user_data,
    gpointer user_data);

void blink_web_view_set_javascript_dialog_handler(
    BlinkWebView* web_view,
    BlinkJSDialogRequestCallback callback,
    gpointer user_data);

Show your own dialog and, once the user has answered, you must call
response_callback (the renderer waits until you do). This may be
asynchronous — return TRUE from the handler, show the dialog, and call
response_callback when a button is pressed.

  • success: TRUE for OK, FALSE for cancel
  • input_text: the text entered for a prompt (NULL otherwise)
  • Returning FALSE from the handler falls back to the default behaviour
  • Pass NULL as callback to unset

File chooser

blink_web_view_set_file_chooser_handler()

Receives <input type="file"> requests.

Signature:

typedef gboolean (*BlinkFileChooserRequestCallback)(
    BlinkWebView* web_view,
    gboolean allow_multiple,
    const char* accept_types,
    gpointer user_data);

void blink_web_view_set_file_chooser_handler(
    BlinkWebView* web_view,
    BlinkFileChooserRequestCallback callback,
    gpointer user_data);
  • allow_multiple: whether multiple selection is allowed
  • accept_types: comma-separated MIME types / extensions (may be NULL)

Open a GtkFileDialog (or your own UI) in the handler, then call:

blink_web_view_file_chooser_response()

Signature:

void blink_web_view_file_chooser_response(BlinkWebView* web_view,
                                          const char** file_paths);

file_paths is a NULL-terminated array of paths. Pass NULL to cancel.

const char *paths[] = { "/home/user/photo.jpg", NULL };
blink_web_view_file_chooser_response(view, paths);

Downloads

blink_web_view_set_download_handler()

Called before a download starts; returns the destination.

Signature:

typedef char* (*BlinkDownloadRequestCallback)(
    BlinkWebView* web_view,
    const char* url,
    const char* suggested_filename,
    const char* mime_type,
    gpointer user_data);

void blink_web_view_set_download_handler(
    BlinkWebView* web_view,
    BlinkDownloadRequestCallback callback,
    gpointer user_data);

Return an absolute destination path allocated with g_strdup() or similar
(BlinkGTK frees it). Return NULL to save to the default ~/Downloads/.

HTTP authentication

blink_web_view_set_auth_handler()

Receives HTTP 401 / proxy 407 authentication requests.

Signature:

typedef gboolean (*BlinkAuthRequestCallback)(
    BlinkWebView* web_view,
    const char* url,
    const char* realm,
    gboolean is_proxy,
    gpointer user_data);

void blink_web_view_set_auth_handler(
    BlinkWebView* web_view,
    BlinkAuthRequestCallback callback,
    gpointer user_data);

Return TRUE from the handler and, once you have credentials, call the
following (asynchronously is fine if you show a login dialog):

blink_web_view_auth_response()

Signature:

void blink_web_view_auth_response(BlinkWebView* web_view,
                                  const char* username,
                                  const char* password);

Pass NULL as username to cancel.

Certificate errors

blink_web_view_set_certificate_error_handler()

Decides whether to proceed past an SSL certificate error.

Signature:

typedef gboolean (*BlinkCertErrorCallback)(
    BlinkWebView* web_view,
    const char* url,
    const char* error_description,
    gpointer user_data);

void blink_web_view_set_certificate_error_handler(
    BlinkWebView* web_view,
    BlinkCertErrorCallback callback,
    gpointer user_data);

Return TRUE to proceed, FALSE to block.

Note: the default when no handler is set is "log and allow". That is a
development default — for products that display arbitrary external sites,
set a handler that returns FALSE to block. Kiosks and readers that only
display the application's own content are a different matter.

Complete example: download destination plus a custom confirm()

#include <blink_gtk/blink_gtk.h>
#include <gtk/gtk.h>

static char* on_download(BlinkWebView *view, const char *url,
                         const char *suggested, const char *mime,
                         gpointer data) {
    /* Save into an app-specific folder */
    char *dir = g_build_filename(g_get_home_dir(), "MyAppDownloads", NULL);
    g_mkdir_with_parents(dir, 0700);
    char *dest = g_build_filename(dir, suggested ? suggested : "download.bin",
                                  NULL);
    g_free(dir);
    return dest;  /* freed by BlinkGTK */
}

static gboolean on_js_dialog(BlinkWebView *view,
                             BlinkJSDialogType type,
                             const char *message,
                             const char *default_prompt,
                             BlinkJSDialogResponseCallback respond,
                             gpointer respond_data,
                             gpointer user_data) {
    if (type == BLINK_JS_DIALOG_CONFIRM) {
        g_print("confirm: %s -> answering OK\n", message);
        respond(TRUE, NULL, respond_data);
        return TRUE;
    }
    return FALSE;  /* default behaviour for everything else */
}

int main(int argc, char **argv) {
    blink_gtk_init(&argc, &argv);

    GtkWidget *win = gtk_window_new();
    gtk_window_set_default_size(GTK_WINDOW(win), 1024, 768);

    GtkWidget *view = blink_web_view_new();
    gtk_window_set_child(GTK_WINDOW(win), view);

    blink_web_view_set_download_handler(BLINK_WEB_VIEW(view), on_download, NULL);
    blink_web_view_set_javascript_dialog_handler(BLINK_WEB_VIEW(view),
                                                 on_js_dialog, NULL);

    gtk_window_present(GTK_WINDOW(win));
    blink_web_view_load_uri(BLINK_WEB_VIEW(view), "https://example.com/");

    return blink_gtk_run_main_loop();
}

cc -o handlers-demo handlers-demo.c $(pkg-config --cflags --libs blinkgtk-0.1)
