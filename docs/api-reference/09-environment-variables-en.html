That page lists every environment variable BlinkGTK reads. For example,
BLINKGTK_DISABLE_SITE_ISOLATION (turns off per-site process isolation, which weakens protection) and
BLINKGTK_PRESENT_POLICY (stops putting frames on screen for a window nobody is watching) are both there.
