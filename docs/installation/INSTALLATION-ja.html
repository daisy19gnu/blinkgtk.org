BlinkGTK インストールガイド

BlinkGTK の バイナリ配布物 をインストールする手順です。BlinkGTK は
WebKitGTK と同様に runtime（アプリの実行に必要）と devel（BlinkGTK を
組み込むアプリの開発に必要）を分割配布します。GitHub Releases からバイナリ
（RPM / DEB / tarball）を取得してください。ソースからのビルドは配布物には
含まれません（バイナリ配布）。

システム要件

項目 要件
CPU x86_64 (64-bit)
メモリ 最小 2GB、推奨 4GB 以上
ディスク runtime 展開に約 700MB
OS Linux (Fedora 44+, Ubuntu 24.04+, Debian 13+)
ディスプレイ Wayland のみ（X11 非対応）
GTK4 >= 4.6.0
GLib >= 2.70.0

ランタイム依存（アプリ実行に必要な共有ライブラリ）:

# Fedora / RHEL
sudo dnf install gtk4 glib2 wayland vulkan-loader
# Debian / Ubuntu
sudo apt install libgtk-4-1 libglib2.0-0 libwayland-client0 libvulkan1

Chromium ランタイム一式（V8 / Blink / Viz 等の 500 以上の .so とリソース）は
runtime パッケージの private ディレクトリ（/usr/lib64/blinkgtk-0.1/）に
同梱されるため、別途インストールは不要です。

パッケージ構成（runtime / devel）

パッケージ 用途 主な内容

|

blinkgtk-bin（runtime） | アプリ実行 | /usr/lib64/libblinkgtk-0.1.so.0（公開 ABI）+ /usr/lib64/blinkgtk-0.1/（Chromium 一式・private）+ /usr/libexec/blinkgtk-0.1/（simple_browser）+ THIRD_PARTY_NOTICES.html |
|

blinkgtk-bin-devel（devel） | consumer 開発 | ヘッダ（/usr/include/blinkgtk-0.1/）+ pkg-config（/usr/lib64/pkgconfig/blinkgtk-0.1.pc）+ .so symlink |
|

blinkgtk-bin-gir（gir） | Python/Rust 等の introspection | BlinkGTK-0.1.typelib |

アプリを動かすだけなら runtime のみ、BlinkGTK を組み込むアプリを開発する場合は
devel（+ gir） も導入します。

インストール方法

配布アセットは GitHub Releases から取得します（SHA256SUMS で検証してください）。

Fedora / RHEL（RPM）

# runtime のみ（アプリ実行）
sudo dnf install ./blinkgtk-bin-<VERSION>-1.fc44.x86_64.rpm

# 開発する場合は devel + gir も
sudo dnf install ./blinkgtk-bin-devel-<VERSION>-1.fc44.x86_64.rpm \
                 ./blinkgtk-bin-gir-<VERSION>-1.fc44.x86_64.rpm

Debian / Ubuntu（DEB）

sudo apt install ./libblinkgtk-0.1-0_<VERSION>_amd64.deb        # runtime
sudo apt install ./libblinkgtk-0.1-dev_<VERSION>_amd64.deb      # devel

Tarball（FHS レイアウト）

runtime / devel とも FHS レイアウト（usr/lib64/...）です。root（/）に展開します。

# runtime
sudo tar xzf blinkgtk-<VERSION>-linux-x86_64.tar.gz -C /
sudo ldconfig                                    # ld.so.conf.d を反映

# devel（consumer 開発時のみ）
sudo tar xzf blinkgtk-devel-<VERSION>-linux-x86_64.tar.gz -C /

ldconfig は runtime に含まれる /etc/ld.so.conf.d/blinkgtk-0.1.conf
（private ディレクトリを検索パスに追加）を反映するために実行します。

インストール確認

runtime（アプリ実行）

# 公開 ABI が ld.so で解決されるか
$ ldconfig -p |

grep libblinkgtk-0.1
    libblinkgtk-0.1.so.0 (libc6,x86-64) => /usr/lib64/libblinkgtk-0.1.so.0

# デモブラウザ（Wayland セッションで）
$ /usr/libexec/blinkgtk-0.1/simple_browser

devel（pkg-config）

$ pkg-config --modversion blinkgtk-0.1
<VERSION>

$ pkg-config --cflags blinkgtk-0.1
-I/usr/include/blinkgtk-0.1 -I/usr/include/gtk-4.0 ... -pthread

$ pkg-config --libs blinkgtk-0.1
-L/usr/lib64 -L/usr/lib64/blinkgtk-0.1 -L/usr/lib64/blinkgtk-0.1/chromium \
  -lblinkgtk-0.1 -lbase_allocator_partition_allocator_src_partition_alloc_allocator_shim ...

重要: --libs に PartitionAlloc allocator shim
（-lbase_allocator_partition_allocator_src_partition_alloc_allocator_shim）が
含まれます。consumer は 必ず pkg-config 経由でリンクしてください（shim を
実行ファイルに直接リンクしないと Chromium のナビゲーションが失敗します —
Issue #90）。

gir（Python / PyGObject）

$ python3 -c "import gi; gi.require_version('BlinkGTK','0.1'); from gi.repository import BlinkGTK; print('BlinkGTK OK')"
BlinkGTK OK

consumer アプリのビルド

BlinkGTK を組み込むアプリは pkg-config でビルドします（shim の直接リンクが
自動で付与されます）。

cc my_app.c -o my_app $(pkg-config --cflags --libs blinkgtk-0.1)

詳細は consumer 統合ガイド（ライフサイクル /
WebView 埋め込み / GPU モード / 注入 等）を参照してください。

アンインストール

RPM

sudo dnf remove blinkgtk-bin blinkgtk-bin-devel blinkgtk-bin-gir

DEB

sudo apt remove libblinkgtk-0.1-0 libblinkgtk-0.1-dev

Tarball

tarball は FHS 配置のため、展開したファイルを手動で削除します（パッケージ
管理を使う RPM/DEB を推奨）。主な配置先: /usr/lib64/libblinkgtk-0.1.so*,
/usr/lib64/blinkgtk-0.1/, /usr/libexec/blinkgtk-0.1/,
/etc/ld.so.conf.d/blinkgtk-0.1.conf, /usr/include/blinkgtk-0.1/（devel）,
/usr/lib64/pkgconfig/blinkgtk-0.1.pc（devel）。削除後に sudo ldconfig。

トラブルシューティング

1. libblinkgtk-0.1.so.0: cannot open shared object file

ld.so の検索パスに private ディレクトリが反映されていません。

sudo ldconfig                          # /etc/ld.so.conf.d/blinkgtk-0.1.conf を反映
ldconfig -p |

grep libblinkgtk-0.1     # 解決を確認

2. pkg-config が blinkgtk-0.1 を検出しない

devel パッケージ未導入、または PKG_CONFIG_PATH 未設定です。

# devel を導入 (上記) するか、tarball 配置時は:
export PKG_CONFIG_PATH=/usr/lib64/pkgconfig:$PKG_CONFIG_PATH
pkg-config --modversion blinkgtk-0.1

3. 自作アプリで黒画面 / ナビゲーション失敗（Issue #90）

consumer が allocator shim を直接リンクしていません。pkg-config 経由で
リンクしてください（pkg-config --libs blinkgtk-0.1 が shim を含みます）。
確認: `readelf -d ./my_app | grep NEEDED |

grep partition_alloc_allocator_shim`
が 1 件あること。

4. Python import エラー（Namespace BlinkGTK not available）

gir パッケージ未導入、または GI_TYPELIB_PATH 未設定です。

# gir を導入 (上記) するか、tarball 配置時は:
export GI_TYPELIB_PATH=/usr/lib64/girepository-1.0:$GI_TYPELIB_PATH

5. Failed to open Wayland display

BlinkGTK は Wayland のみ対応です（X11 非対応）。

echo $WAYLAND_DISPLAY    # 空なら Wayland セッションで再ログイン
