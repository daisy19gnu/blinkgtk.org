プライバシーポリシー

このサイト (blinkgtk.org / blinkgtk.com) で、何を集め、何を集めないかをまとめます。 BlinkGTK ライブラリ本体については、末尾の「ライブラリ本体について」をご覧ください。

まとめ

  • 閲覧状況の計測は、同意をいただいた場合にだけ行います。同意がなければ計測用のスクリプトを読み込みません
  • お名前・メールアドレスなど、個人を特定する情報は集めません
  • 判断はあとから何度でも変えられます (このページの下にボタンがあります)

同意をいただいた場合に集めるもの

Google Analytics 4 を使い、次のものを集めます。いずれも集計して傾向を見るためのもので、 個人を割り出すためのものではありません。

集めるもの何に使うか
閲覧したページの URLどの資料が読まれているかを知り、手を入れる順番を決めるため
どこから来たか (参照元)どの経路で見つけていただいたかを知るため
おおよその地域 (国・都市)どの言語の資料を厚くするかを決めるため
ブラウザ・OS・画面幅の種別表示の確認をどの環境で行うかを決めるため
ランダムな識別子 (Cookie)同じ方の複数ページ閲覧を 1 回として数えるため

IP アドレスは Google 側で丸められ、そのままの形では保存されません (anonymize_ip を明示的に指定しています)。

集めないもの

お名前、メールアドレス、勤務先、入力された文字列、その他あなたを特定できる情報は 集めません。Google Analytics の利用規約でも、これらを送信することは禁じられています。

同意しない場合

「使わない」を選ぶと、計測用のスクリプトは一切読み込まれません。 選択はこのブラウザの中にだけ記録され、次からは尋ねません。サイトの内容や ダウンロードには何の制限もかかりません。

同意とは関係なく記録されるもの

正直に書いておきます。このサイトは GitHub Pages で配信しており、 配信元である GitHub 社のサーバーには、アクセス日時・IP アドレス・ ブラウザの種類などが記録されます。これは Web サイトを配信する仕組みそのものに 伴うもので、当プロジェクトが止めることはできません。 取り扱いは GitHub 社のプライバシーに関する声明によります。

同様に、配布物のダウンロード数は GitHub の公開 API から得られる集計値で、 誰がダウンロードしたかは当プロジェクトからは分かりません。

第三者への提供

集めた情報を第三者に販売・提供することはありません。 Google Analytics は集計を行うための委託先であり、 取り扱いは Google のプライバシー ポリシーによります。

保存期間

Google Analytics 側の保存期間は 14 か月に設定しています。 それを過ぎたものは自動的に削除されます。

判断を変える

下のボタンで、同意するかどうかをもう一度選び直せます。

ブラウザ側で Cookie を拒否する、 Google のオプトアウト アドオンを使う、 といった方法でも計測を止められます。

ライブラリ本体について

BlinkGTK ライブラリ自体は、いかなる情報も外部に送信しません。 利用状況の収集、クラッシュレポートの自動送信、更新確認のいずれも行いません。 ネットワーク通信が発生するのは、あなたのアプリケーションが読み込むよう指示した コンテンツを取りに行くときだけです。

これは設計上の約束です。確認したい場合はソースを追ってください。 外部へ送信する経路は存在しません。
