Privacy policy

This covers what the BlinkGTK websites (blinkgtk.org / blinkgtk.com) collect and what they do not. For the library itself, see “About the library” at the end.

In short

  • We measure visits only if you agree to it. Without consent, no measurement script is loaded at all
  • We do not collect anything that identifies you — no name, no email address
  • You can change your mind at any time (there is a button further down this page)

What we collect once you agree

We use Google Analytics 4. Everything below is aggregated to see trends; none of it is used to work out who you are.

CollectedWhat it is for
URL of the page viewedTo learn which documents are actually read, and decide what to improve first
Where you came from (referrer)To learn how people find the project
Approximate location (country, city)To decide which language deserves more work
Browser, OS, screen size categoryTo decide which environments to test rendering against
A random identifier (cookie)To count several pages viewed by one person as one visit

IP addresses are truncated by Google and are not stored in full (we set anonymize_ip explicitly).

What we do not collect

No names, email addresses, employers, text you type, or anything else that identifies you. Sending such data is also forbidden by the Google Analytics terms of service.

If you decline

Choosing “No thanks” means the measurement script is never loaded. Your choice is stored in this browser only, and you will not be asked again. Nothing about the site or the downloads is restricted.

What is recorded regardless of consent

To be straightforward about it: this site is served from GitHub Pages, and GitHub's servers record access times, IP addresses and browser types as part of serving any website. This project cannot switch that off. It is governed by the GitHub General Privacy Statement.

Likewise, download counts for the released packages are aggregate figures from GitHub's public API; this project cannot see who downloaded anything.

Sharing

We do not sell or pass on what we collect. Google Analytics acts as a processor for the aggregation; its handling is governed by the Google Privacy Policy.

Retention

Retention in Google Analytics is set to 14 months. Data older than that is deleted automatically.

Change your mind

Use the button below to make the choice again.

You can also block cookies in your browser, or install the Google opt-out add-on.

About the library

The BlinkGTK library itself sends nothing anywhere. No usage statistics, no automatic crash reports, no update checks. Network traffic happens only when your application asks it to load content.

This is a design commitment. If you want to confirm it, read the source — there is no path that sends anything outward.
